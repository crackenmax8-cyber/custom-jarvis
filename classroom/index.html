One-time setup, then it's one-click sign-in

You'll sign in with your normal Google account — no new passwords, and after the first time Google won't even re-ask for permission. But first, Google requires every app that reads Classroom to be registered once (that registration is called a "Client ID" — it identifies this app, not you):

  1. Open console.cloud.google.com and create a project (any name, e.g. "ClassMate").
  2. APIs & Services → Library → search "Google Classroom API" → Enable.
  3. OAuth consent screen → External → app name + your email → add yourself as a test user.
  4. Credentials → Create credentials → OAuth client ID → Web application → under "Authorized JavaScript origins" add http://localhost:8000.
